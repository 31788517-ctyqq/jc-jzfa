登录框页面

下面给你的是**iPhone 16 Pro Max（440px设计宽度）登录页高保真静态代码**，基于你修改后的设计要求：



---

# HTML

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<title>登录</title>

<link rel="stylesheet" href="style.css">

<link rel="stylesheet"
href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">

</head>

<body>

<div class="phone">

    <!-- 顶部 -->
    <div class="hero">

        <div class="hero-content">
            <h1>Hello!</h1>
            <p>欢迎来到竞彩推荐监控系统</p>
        </div>

        <img
            src="eagle.png"
            class="eagle"
            alt="eagle"
        >

    </div>

    <!-- 登录卡片 -->
    <div class="login-card">

        <div class="input-box">
            <i class="fa-regular fa-user"></i>
            <input
                type="text"
                placeholder="请输入账号"
            >
        </div>

        <div class="input-box">

            <i class="fa-solid fa-lock"></i>

            <input
                id="password"
                type="password"
                placeholder="请输入密码"
            >

            <button
                class="eye-btn"
                onclick="togglePwd()">

                <i id="eye"
                class="fa-regular fa-eye"></i>

            </button>

        </div>

        <label class="agree">

            <input type="checkbox" checked>

            <span class="checkmark"></span>

            登录即代表同意
            <a href="#">《用户协议》</a>

        </label>

        <button class="login-btn">
            登录
        </button>

    </div>

</div>

<script>

function togglePwd(){

    const pwd=document.getElementById('password');
    const eye=document.getElementById('eye');

    if(pwd.type==="password"){
        pwd.type="text";
        eye.className="fa-regular fa-eye-slash";
    }else{
        pwd.type="password";
        eye.className="fa-regular fa-eye";
    }

}

</script>

</body>
</html>
```
