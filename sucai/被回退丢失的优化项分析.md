## 五、修复建议

### 5.1 不要直接部署 local/auth-preview

当前 local 分支虽然比 master 先进，但包含大量 Vite 灾难的修复 commit（15+ 个），历史不干净。

### 5.2 推荐方案

```
1. 从 local/auth-preview 的当前稳定代码（09d4bb09）为基础
2. 完成 Phase 1-4 的代码优化（CSS 变量化 + 清理 + 规范）
3. Phase 4 全量测试全部通过
4. 合入 master → 打 tag v12.0-stable → 部署

结果：
  • master 获得全部 50+ 个 missing 的 feat/perf/fix
  • 同时获得经过完整验证的规范化代码
  • master = local/auth-preview = 最优版本
```

### 5.3 最终状态

```
期望的最终 master:
  084c49fb + 50+ 个 lost commits + Phase 1-4 优化 = v12.0-stable
  ↑ 当前生产            ↑ 补回                     ↑ 新增规范化
```
