# 本地-生产环境落差导致返工的分析报告

> 2026-06-16 | 基于 754 个 commit 的模式分析

---

## 核心发现

**每一次 feat/build 上线后，平均需要 3~20 个紧急 fix commit 来兜底。**

这不是个别现象，而是系统性的"本地测试不足 + 生产环境差异"导致的发布后返工循环。

## 三、根本原因

### 3.1 测试环境 ≠ 生产环境

```
本地开发环境（Windows）                   生产环境（CentOS/Ubuntu）
├── Node 直接启动                          ├── PM2 cluster
├── 无 Nginx 代理                          ├── Nginx 反向代理 + 多层缓存
├── 无 Service Worker                      ├── SW 拦截 + 预缓存
├── 本地文件系统                            ├── 服务器文件系统 + chattr
├── Windows 换行 CRLF                      ├── Linux 换行 LF
├── PowerShell UTF-8 BOM                   ├── 标准 UTF-8
├── 本地有全部 node_modules                 ├── 只装了部分依赖
└── Node 24                                └── 服务器 Node 版本可能不同
```

### 3.2 本地验证不充分

- **只验证了功能逻辑** → 没验证部署后的缓存/代理/路径
- **只启动了一次** → 没模拟 PM2 重启后的数据持久性
- **只测试了 Chrome** → 没测试 SW 缓存场景
- **只看 HTTP 200** → 没看浏览器实际渲染效果

### 3.3 发布流程缺门禁

```
当前流程:
  开发 → git commit → python deploy.py → 祈祷
                                     ↑
                              没有验证步骤！

应有流程:
  开发 → pre-commit 检查 → 本地全量测试 → E2E → pre-deploy 验证 → deploy → 5层验证
```

## 四、优化措施

### 4.1 必须本地模拟的生产环境特性

| 本地模拟项 | 方法 |
|-----------|------|
| SW 缓存 | `node server/index.js` 启动后，浏览器打开 → F12 Application → Service Workers |
| Nginx 路径 | 在本地也用 `/preview/` 和 `/assets/` 路径测试 |
| PM2 重启数据持久性 | 启动 → 写入测试数据 → 重启 → 确认数据仍在 |
| 缓存验证 | 部署后 Ctrl+Shift+R 强制刷新 → 确认看到新内容 |

### 4.2 强制部署前门禁

```
scripts/pre-deploy-check.cjs
  ├── Lint 通过
  ├── P0+P1 测试全绿
  ├── SW 无页面壳缓存
  ├── index.html 无 Vite 污染
  ├── 关键字符串确认
  ├── CSS Design Tokens 检查
  └── npm audit 无高危
```

### 4.3 部署后 5 层验证

```
L1: PM2 status → online
L2: curl :3000/api/health → 200
L3: curl -H "Host:zj.100qiu.com" :80/api/health → 200
L4: 业务 API match-list → code=0 + 数据非空
L5: 浏览器打开 → SW 未拦截 + 无 404
```

### 4.4 本地-生产差异检查清单

部署前逐项确认：

- [ ] 新增 `require()` 的模块在 `deploy.py` 范围内？
- [ ] 新增 npm 包已在服务器 `npm install`？
- [ ] 静态资源路径匹配 Nginx 映射表？
- [ ] 日期处理使用了 `datetime.todayCN()`？
- [ ] 数据写入使用了 `database.getAdapter()`？
- [ ] SW 未缓存 HTML 壳（`PAGE_SHELL`）？
- [ ] 前端文件已加 `?v=` 版本戳？
- [ ] 无 Windows 专有路径（`\\` → `/`）？
