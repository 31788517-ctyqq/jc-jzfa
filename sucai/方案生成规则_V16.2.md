## 四、通用规则

| 规则 | 说明 |
|------|------|
| **投注金额** | 每方案1000元（250注 × 10张票 × 25倍） |
| **荷兰式均分** | 双选/三选：`1000 / Σ(1/odds)`，赔率高的投得少 |
| **串关计算** | 每场荷兰式后连乘 × 1000 |
| **奖金取整** | `Math.round()` |
| **中奖判定** | ①midou310 result → ②sporttery lotteryResult → ③judgeByScore |
| **日产出** | <50场时最多保留前7个方案；≥50场时保留全部 |
| **缓存** | snapshots/YYYY-MM-DD.json |
