       │
       ▼

  ├─ com.quncai.alipay.*      → 支付宝 SDK 封装
  │   ├─ SDKPayRequestBuilderImpl
  │   ├─ WapPayRequestBuilderImpl
  │   ├─ RSANotifyVeryfyImpl
  │   └─ WapNotifyVerifyImpl
  ├─ com.quncai.weixin.*      → 微信支付封装
  │   ├─ SDKWeiXinRequestImpl
  │   └─ WeixinLoginBuilder
  ├─ com.quncai.tonglian.*    → 通联支付
  │   └─ SybPayService

  └─ member/chargeNotify*.php → Tomcat/Struts2 路由分发

## 十、对 JC-ZJFA 项目的可用信息

### 可直接复用的支付参数

1. **支付宝**
   - partnerID + MD5 Key → Node.js `alipay-sdk` 直接接入
   - RSA 密钥对 → 用于签名验签
   - WAP 网关地址 → 移动端支付

2. **微信支付**
   - AppId / AppSecret / PartnerId / PartnerKey → 微信支付 v2 接入
   - API Endpoints → 统一下单、AccessToken

3. **其他渠道**
   - 现在支付 / 通联支付 / 威富通 作为备选渠道
