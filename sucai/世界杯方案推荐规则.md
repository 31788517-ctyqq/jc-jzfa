# 世界杯方案推荐规则 *（已投产，ed7668b8）*

基于 `server/core/plan-generator.js` → `generatePlansForGroup(isWC=true)` 的世界杯赛事差异化规则。

> **核心思想**：放宽排名约束（topN=5~7）产生更多方案 + 盈利门槛兜底质量（10%~80%）
>
> **适用范围**：仅适用于 **2026 年世界杯**联赛标签的比赛（`leagueName` 包含"世界杯"）。非世界杯标签比赛沿用常规 `专家方案生成条件.md`。
>
> **展示规则**：世界杯方案（命名 `世界杯01`~`世界杯08`）排在常规方案前面。

---

## 通用数据源与术语

| 术语 | 含义 |
|------|------|
| **方向排行** | 基于 `matchDataMap.recs` 自建排行，按 `expertCount` 降序 |
| **方向前 N 名** | 该方向在当日 WC 组所有方向中排名 ≤ N |
| **推荐人数 ≥ K** | 该场次该方向的 `recs.num` 总和 ≥ K |
| **合赔** | 两场赔率乘积（2串1 的回报倍数） |
| **盈≥X%** | `maxPrize ≥ 1000×(1+X%)`，确保方案有最低利润空间 |
| 投注金额 | 1000 元/方案（250注 × 10票 × 25倍） |

## 方案一：平、让平 × 让负（2 串 1）

| 环节 | 条件 |
|------|------|
| 比赛总数 | ≥ 3 场 |
| 第一场 | 平/让平 排前 **7** 名 + ≥10 人 |
| 第一场门禁 | SPF 平赔率有效（>0），否则整案跳过 |
| 第二场 | 让负 排前 **7** 名 + ≥10 人（排除第一场）|
| 盈利门槛 | maxPrize ≥ 1100（盈≥10%） |

---

## 方案二：总进球-2、3球 × 让负（2 串 1）

| 环节 | 条件 |
|------|------|
| 比赛总数 | ≥ 3 场 |
| 第一场 | 总进球-2、3球 排前 **5** 名 + ≥10 人 |
| 第一场赔率 | totalGoals[2] 和 totalGoals[3] 均有效 |
| 第二场 | 让负 ≥10 人（排除第一场），方向排前 **5** 名 |
| 合赔 | ≥ 2.0 |

## 与常规方案的对比差异

| 方案 | 常规方案 | 世界杯差异化 |
|------|---------|-------------|
| 一 | 无排行/盈利约束 | **双场均前7 + 各≥10人 + 盈≥10%** |
| 二 | 让负≥10，合赔≥2.0 | **双场均前5 + 各≥10人 + 盈≥80%** |
| 三 | 胜≥35，合赔≥2.0 | **第二场前5 + 胜≥50 + 盈≥30%** |
| 四 | ≥6场，无排行 | **≥3场 + 双场均前6 + 胜≥20 + 盈≥30%** |
| 五 | ≥6场，无排行 | **≥4场 + 双场均前7 + A≥1.3,B>1.4** |
| 六 | ≥2场 | **该场前6 + 盈≥50%** |
| 七 | 无人数下限 | **≥10人 + 盈≥10%** |
| 八 | — | **世界杯专属，胜≥50 + 前2 + 盈≥5%** |

## 实现架构

```
generateExpertPlans(mList, matchDataMap, dateStr)
├── 按 leagueName 拆分：wcMatches + regularMatches
├── generatePlansForGroup(wcMatches, ..., isWC=true, planPrefix='世界杯')
│   ├── 方案一：≥3场 + 双场均前7 + 各≥10 + 平赔率门禁 + 盈≥10%
│   ├── 方案二：≥3场 + 双场均前5 + 各≥10 + ≥2.0 + 盈≥80%
│   ├── 方案三：第二场前5 + 胜≥50 + ≥2.0 + 盈≥30%
│   ├── 方案四：≥3场 + 双场均前6 + 胜≥20 + 盈≥30%
│   ├── 方案五：≥4场 + 双场均前7 + 交叉配对 + 合赔≥1.5
│   ├── 方案六：≥2场 + 该场前6 + 盈≥50%
│   ├── 方案七：有单关 + ≥10人 + 盈≥10%
│   └── 方案八：有单关 + 胜≥50 + 前2 + 盈≥5%
│
└── generatePlansForGroup(regularMatches, ..., isWC=false, planPrefix='方案')
    └── 保持常规 7 方案不变
```

> **代码位置**：`server/core/plan-generator.js` → `generatePlansForGroup()`
