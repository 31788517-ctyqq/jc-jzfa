# 竞彩全维度数据 JS 字段解释规范 (Ultimate Final V4.3)

## 📂 一、基础信息与赛事标识 (Base Info)

| JS 字段名 | 中文释义 | 业务口径与逻辑说明 |
| :--- | :--- | :--- |
| `lineId` | 赛事编号 | 竞彩官方定义的比赛唯一流水 ID。 |
| `matchTimeStr` | 比赛时间 | 赛事的官方预定开球时间 (YYYY-MM-DD HH:mm:ss)。 |

| `guestTeam` | 客队名称 | 比赛的客场球队全称。 |
| `gameShortName` | 赛事简称 | 联赛或杯赛的中文简写（如：英超、日职）。 |

## 💪 二、球队基本面与历史特征 (Fundamentals)

| JS 字段名 | 中文释义 | 业务口径与逻辑说明 |
| :--- | :--- | :--- |
| `homePower` / `guestPower` | 主/客队战力指数 | 综合身价、排名、战绩等加权得出的实力量化评分（0-100）。 |
| `homeJiFenHomeAll` | 主队总场均积分 | 主队当前赛季所有比赛的场均得分（胜3/平1/负0）。 |

| `homeWinPan` / `guestWinPan` | 主/客队赢盘回报率 | 统计当前赛事亚指回报率（0最低，2最高，除以2可近似视为赢盘率）。 |

| `jiaoFenMatch1/2` | 过往两次交锋战绩 | 双方最近两次直接交锋的具体日期、比分及赛果。 |

## 🧮 六、北单实时奖金与换算比例 (Live Award & Odds)

> 此模块涵盖北单特有的SP值及其与投注比例的动态换算逻辑。

| JS 字段名 | 中文释义 | 业务口径与逻辑说明 |
| :--- | :--- | :--- |
| `homeWinAward` | 北单主胜实时 SP | 北单玩法中主胜项的即时奖金。 |
| `drawAward` | 北单平局实时 SP | 北单玩法中平局项的即时奖金。 |
| `guestWinAward` | 北单客胜实时 SP | 北单玩法中客胜项的即时奖金。 |

### 核心业务逻辑说明

1.  **玩法判定 (rq 逻辑)**：
    *   若 `rq == 0`：以上三个字段对应北单**胜平负**玩法的实时 SP。
    *   若 `rq != 0`：以上三个字段对应北单**让球胜平负**玩法的实时 SP。

2.  **投注比例换算 (市场支持度)**：
    *   该 SP 是根据实际投注比例动态计算的。
    *   **换算公式**：`理论支持比例 = 1 / 实时 SP`
    *   **解读**：此比例反映了当前北单奖池内资金的实际分布情况。SP 值越高，对应的理论支持比例越低（冷门）；反之则越热。
