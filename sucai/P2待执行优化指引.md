## #6: innerHTML 替换为 DOM API

### 当前状态

| 文件 | innerHTML 处数 | 是否在 ⛔不可动区域 |
|------|:---:|:---:|
| `plans.js` | 27 处 | ✅ 不可动 |
| `admin.js` | 24 处 | ⚠️ 可改 |
| `backtest.js` | 16 处 | ⚠️ 可改 |
| `home.js` | 12 处 | ✅ 不可动 |
| `confirm-scheme.js` | 9 处 | ✅ 不可动 |

### 暂缓原因

- `plans.js`、`home.js`、`confirm-scheme.js` 在不可动区域（反复修复才稳定）
- 替换 innerHTML 可能破坏现有渲染逻辑
- 收益有限（主要用于 XSS 防护，而本项目是内部使用）

### 执行时机

下次对可改文件（admin.js、backtest.js）做功能修改时，顺手替换该页面的 innerHTML。

### 替换模式

```javascript
// 旧: 直接用 innerHTML
el.innerHTML = '<div class="card">' + text + '</div>';

// 新: 使用 DOM API
var div = document.createElement('div');
div.className = 'card';
div.textContent = text;  // 纯文本用 textContent
el.appendChild(div);

// 如果有 HTML 结构需要保留：
var div = document.createElement('div');
div.className = 'card';
div.innerHTML = sanitizedHTML;  // 仅当内容已转义
el.appendChild(div);
```

## #7: 全局空状态组件 ✅ 已执行

已在 `app.css` 添加：
- `.empty-state` — 居中空状态（图标 + 文字）
- `.empty-state-icon` — 空状态图标
- `.loading` — loading spinner（自动旋转动画）
- `.error-state` — 错误状态 + 重试按钮
- `@keyframes jczj-spin` — 旋转动画

### 使用示例

```html
<!-- 空状态 -->
<div class="empty-state">
  <div class="empty-state-icon">📭</div>
  <div class="empty-state-text">暂无数据</div>
</div>

<!-- loading -->
<div class="loading">加载中...</div>

<!-- 错误状态 -->
<div class="error-state">
  <span>加载失败</span>
  <button class="error-state-retry" onclick="location.reload()">重试</button>
</div>
```
