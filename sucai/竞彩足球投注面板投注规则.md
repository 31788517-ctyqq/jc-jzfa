# 竞彩足球玩法规则清单（用于投注面板设计）


## 一、基础规则

**竞猜对象**：国家体育总局体育彩票管理中心选定的国际重要足球比赛。

**比赛时长**：全场90分钟（含伤停补时），不含加时赛和点球大战。

**返奖率**：彩票奖金按销售额的71%（部分地区为73%）计提，其中当期奖金72%，调节基金1%。

**每注金额**：2元人民币。

**单张彩票最高投注金额**：不超过20000元人民币。

**多倍投注倍数**：2至99倍。

**兑奖有效期**：开奖结果公布后60个自然日内。

**个人所得税**：单注奖金超过1万元需缴纳20%个人所得税，由体彩中心代扣代缴。


## 二、五大玩法

### （一）胜平负

猜主队全场90分钟（含伤停补时）的比赛结果。共3种选项：

| 代码 | 选项 | 说明 |
|------|------|------|
| 3 | 胜 | 主队胜，客队负 |
| 1 | 平 | 主队与客队打平 |
| 0 | 负 | 主队负，客队胜 |

**串关上限**：最多8关。


### （二）让球胜平负

当两队实力悬殊时，采用让球方式调整胜负关系。让球数由官方在赛程公布时一并确定，开售后维持不变。

让球表示法：`（-N）`表示主队让N球，`（+N）`表示主队受让N球（即客队让N球）。

**判断逻辑**：用主队实际进球数 ± 让球数后，与客队进球数比较。

**示例**：`主队（-1）` 即主队让1球
- 主队净胜 ≥ 2球 → 让球胜
- 主队净胜 = 1球 → 让球平
- 主队净胜 ≤ 0球 → 让球负

**串关上限**：最多8关。


### （三）比分

猜全场90分钟（含伤停补时）的具体比分。共31种比分结果选项：

**主队胜比分（13种）** ：
1:0、2:0、2:1、3:0、3:1、3:2、4:0、4:1、4:2、5:0、5:1、5:2、胜其它

**平局比分（5种）** ：
0:0、1:1、2:2、3:3、平其它

**主队负比分（13种）** ：
0:1、0:2、1:2、0:3、1:3、2:3、0:4、1:4、2:4、0:5、1:5、2:5、负其它

> “胜其它”：如5:3、6:1等主队获胜的其他比分；“平其它”：如4:4等打平的其他比分；“负其它”：如4:5、0:8等主队落败的其他比分。

**串关上限**：最多4关。


### （四）总进球数

猜全场90分钟（含伤停补时）双方进球总数。共8种结果选项：

0、1、2、3、4、5、6、7+（即7球或7球以上）

**串关上限**：最多6关。


### （五）半全场胜平负

猜上半场45分钟（含伤停补时）和全场90分钟（含伤停补时）的胜负结果组合。共9种结果选项：

| 选项 | 上半场结果 | 全场结果 |
|------|-----------|---------|
| 胜胜 | 主队胜 | 主队胜 |
| 胜平 | 主队胜 | 平局 |
| 胜负 | 主队胜 | 主队负 |
| 平胜 | 平局 | 主队胜 |
| 平平 | 平局 | 平局 |
| 平负 | 平局 | 主队负 |
| 负胜 | 主队负 | 主队胜 |
| 负平 | 主队负 | 平局 |
| 负负 | 主队负 | 主队负 |

**串关上限**：最多4关。


## 三、投注方式

### 1. 按场次数划分

| 类型 | 说明 |
|------|------|
| 单场投注 | 选择1场比赛进行投注 |
| 过关投注 | 选择2场或2场以上比赛进行串联投注，需全部猜中才能中奖 |

### 2. 按结果数划分

| 类型 | 说明 |
|------|------|
| 单式投注 | 所选每场比赛均只选1种结果 |
| 复式投注 | 某场或某几场比赛选择2种及以上结果 |

### 3. 过关投注分类

| 类型 | 说明 |
|------|------|
| 一般过关 | 前后场次均选择同一种玩法（如全部胜平负） |
| 混合过关 | 不同场次选择不同玩法（如一场胜平负、一场让球胜平负），需同一运动项目，同一场次不同玩法不可混合 |
| M串N | 用M场比赛串成N个不同关数的组合，支持容错，如“3串4”=3个2关+1个3关 |
| 自由过关 | 选定赛事后自主选择过关数，系统自动排列组合（如选6场比赛，同时选4串1和6串1） |

### 4. 串关场次上限

| 玩法 | 最多过关数 |
|------|-----------|
| 胜平负 | 8关 |
| 让球胜平负 | 8关 |
| 总进球数 | 6关 |
| 半全场胜平负 | 4关 |
| 比分 | 4关 |

### 5. 常用串关组合（面板推荐）

- **2串1**：两场全中
- **3串1**：三场全中
- **3串3**：3注2关
- **3串4**：3注2关 + 1注3关
- **4串1**：四场全中
- **4串5**：4注3关 + 1注4关
- **4串11**：6注2关 + 4注3关 + 1注4关
- **5串1**：五场全中
- **6串1**：六场全中
- **8串1**：八场全中


## 四、奖金计算

### 1. 固定奖金机制

竞彩采用固定奖金机制：购买者完成投注时，该投注对应各场比赛的固定奖金即被锁定，出票后奖金不再变动，不受后续赔率调整的影响。

> ⚠️ **投注面板提示**：页面中显示的固定奖金仅供参考，实际中奖金额以出票时刻的固定奖金为准。

### 2. 单场投注奖金计算公式

```
单注奖金 = 2元 × 单场奖金值 × 倍数
```

**示例**：投注某场比赛胜，单场奖金值为6.80元，投注100倍，则中奖金额 = 2 × 6.80 × 100 = 1,360元。

### 3. 过关投注奖金计算公式

```
单注奖金 = 2元 × 所选各场比赛奖金值连乘 × 倍数
```

**示例**：曼联平（固奖4.05）+ 皇马胜（固奖1.56），2串1，单注奖金 = 4.05 × 1.56 × 2 = 12.63元；买100倍即为1,263元。

### 4. 单注最高奖金限额

| 过关场次 | 单注最高奖金限额 |
|----------|----------------|
| 单场 | 10万元 |
| 2场和3场 | 20万元 |
| 4场和5场 | 50万元 |
| 6场及以上 | 100万元 |

### 5. 特殊规则

**无效场次**：
- 单场投注中出现无效场次 → 退款处理
- 过关投注中出现无效场次 → 该场次在所有投注组合中视为无效，按去除该场次后的组合计算奖金

**奖金拆分**：当单注奖金超过最高限额时，按最高限额兑奖。


## 五、赛事异常处理规则

| 场景 | 处理规则 |
|------|---------|
| 开售前比赛时间提前/推迟/取消 | 相应更改销售时间或取消该场次竞猜 |
| 开售后比赛时间提前 | 相应提前截止销售时间；若提前到开售时间内，该场开始前投注有效，之后投注无效 |
| 开售后比赛时间推迟 ≤36小时 | 相应推迟截止销售时间 |
| 开售后比赛时间推迟 >36小时或无法获知推迟时间 | 认定为无效场次 |
| 比赛中中断，36小时内恢复完成 | 认定为有效场次，正常兑奖 |
| 比赛中中断，36小时内未恢复 | 认定为无效场次 |
| 更换比赛场地 | 中立场地换中立场地为有效，否则无效 |
| 参赛队伍变更 | 认定为无效场次 |
| 封闭无观众无转播条件比赛 | 认定为无效场次 |

**无效场次处理**：
- 单场投注：退款处理，60个自然日内办理
- 过关投注：该场次按固定奖金1元计算，或按去除该场次后的组合计算

## 八、投注面板设计要点参考

### 1. 关键校验规则

- 所选比赛场次不可为空，同场比赛不同玩法禁止混合
- 串关场次不得超过各玩法上限
- 复式投注时总注数 × 倍数 × 2元 ≤ 20000元
- 倍数在2-99范围内，每张彩票投注金额上限20000元
- 最大可能奖金超过限额时需提示用户
- 比赛截止时间后禁止投注
- 让球数在投注界面应与主队名称一同显示
- 不允许未满18岁用户投注

### 2. 推荐功能

- **奖金计算器**：即时计算并显示理论最高奖金（不超过限额）
- **热门串关快捷选择**：2串1、3串1、4串1等
- **容错投注意见**：根据用户选择的场次和玩法，展示风险提示信息
- **截止时间倒计时**：每场比赛独立显示停售倒计时
- **赔率波动监控**：实时显示当前赔率
- **复式注数计数**：自动累加复式投注覆盖的总注数
- **已选赛事清单**：清晰展示已选场次和已选结果
