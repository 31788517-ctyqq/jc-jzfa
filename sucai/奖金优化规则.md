
## 奖金优化与统一口径约束声明（必读）

- 奖金优化属于**资金分配策略**，仅调整预算分配与注数组合。
- 奖金优化**不得覆盖**统一口径主字段：`expectedMaxPrize`、`settledPrize`、`passOdds`、`bestProductK`、`totalOdds`。
- 展示层必须优先使用统一口径产物；任何 `optimizedMaxWin` 仅可用于调试，不得作为主展示/主保存口径。
- 同场多选赔率统一使用荷兰式有效赔率，不得回退“同场取最大赔率”。

奖金优化的核心，是**用一种系统性的数学方法来调整你在不同赛果上的投注额，以达到特定的目标。** 目前主流的方法主要有三种：**平衡优化、博热优化、博冷优化**。

下面我用你图片中威尔士队进球数的数据来举例说明。为了让计算过程更清晰，我假设你这场比赛的总预算是**10,000元**。

### 📈 第一步：理解基础数据与核心概念
首先，梳理出每个选项的赔率和对应的标准奖金（假设单注投注额为1元）。

| 赛果选项 | 赔率 | 单注奖金 (1元投注) |
| :--- | :--- | :--- |
| 威尔士进2球 | 3.30 | 3.30元 |
| 威尔士进3球 | 3.30 | 3.30元 |
| 威尔士进4球 | 6.40 | 6.40元 |
| 威尔士进5球 | 13.50 | 13.50元 |

首先，需要引入“**返还率**”的概念。返还率代表了如果对所有赛果进行无风险投注，理论上的回报率。在博彩中，它通常小于100%。这里我们可以通过数据反推：

*   计算投注额在“平衡优化”下的分配，从而得出返还率。将1元资金平均分配到四个选项，总奖金恒为 **3.30元**，因此投资回报率就是3.30元 / 4元 = **82.5%**，这也就是返还率。

### 📊 第二步：主流优化方法对比与计算

理解了返还率，我们来看看几种主要的优化方法。

#### 1. 平衡优化 (Balanced Optimization)：追求稳稳的幸福
这是最基础、也是最稳健的策略。目标是在任何赛果下，获得的最终奖金都趋于相同，实现无风险套利。

*   **计算核心**：根据返还率和不同赛果的赔率，按比例分配资金。
*   **计算公式**：某赛果的投注金额 = 总本金 × (返还率 / 该赛果赔率)

以你的数据为例，计算过程如下：
*   **返还率**：我们从上文已知为 82.5%
*   **进2球**：10000元 × (0.825 / 3.30) = 2500元
*   **进3球**：10000元 × (0.825 / 3.30) = 2500元
*   **进4球**：10000元 × (0.825 / 6.40) ≈ 1289元
*   **进5球**：10000元 × (0.825 / 13.50) ≈ 611元

这样分配后，任何结果下的奖金都是固定的：2500 × 3.30 = **8250元**。你在无风险的情况下获得了总资本的**82.5%**，也就是**8250元**作为回报。

#### 2. 博热优化 (Hot Optimization)：落袋为安，锁定最低收益
如果某场比赛有结果热度极高，比如强队必胜或出现特定进球数，而你认为其他“冷门”结果根本不可能发生，就可以采用博热优化。

*   **核心逻辑**：确保最可能的赛果（“热门”选项）奖金最大化，而为其赛果分配的资金仅能“保本”。
*   **设定目标**：假设你认定威尔士进2球是最大热门，希望它中奖时奖金能最大化，同时保证其他结果（进3球、4球、5球）至少不亏本。
*   **计算方法**：
    1.  **设定保本目标**：为了简化计算，我们先设定其他赛果能收回全部本金（10000元），即“保本”。
        *   进3球的单注奖金为3.30元，要保证10000元保本，需投入金额 = 10000 / 3.30 ≈ 3030元。
        *   同理，进4球需投入 10000 / 6.40 ≈ 1562元。
        *   同理，进5球需投入 10000 / 13.50 ≈ 741元。
    2.  **计算保本总投入**：3030 + 1562 + 741 = 5333元。
    3.  **分配剩余资金**：剩余资金全部投入热门选项（进2球），投入金额 = 10000 - 5333 = 4667元。
*   **最终结果**：
    *   如果热门结果（进2球）出现：奖金高达 4667 × 3.30 ≈ **15401元**，这是最理想的情况。
    *   如果其他结果出现：奖金各自约为10000元，刚好保本。
*   你也可以调整这个保本目标，比如将保本线设为8000元，把更多资金投给热门，追求更高的潜在回报。

#### 3. 博冷优化 (Cold Optimization)：以小博大，追求最大惊喜
与博热优化相反，博冷优化旨在博取高赔率“冷门”带来的巨额回报。

*   **核心逻辑**：确保高赔率的冷门赛果出现时奖金最大化，而为其他可能性分配的资金仅能“保本”。
*   **设定目标**：假设你坚信威尔士会进5球这个爆冷选项。
*   **计算方法**：
    1.  **设定保本目标**：这次我们让其他三个结果进2、3、4球都能保本。
        *   进2球要保本：10000 / 3.30 ≈ 3030元
        *   进3球要保本：10000 / 3.30 ≈ 3030元
        *   进4球要保本：10000 / 6.40 ≈ 1562元
    2.  **计算保本总投入**：3030 + 3030 + 1562 = 7622元。
    3.  **分配剩余资金**：剩余资金全投进5球，投入金额 = 10000 - 7622 = 2378元。
*   **最终结果**：
    *   如果如你所愿，威尔士真的进了5球，奖金高达 2378 × 13.50 ≈ **32103元**，收益非常可观。
    *   如果其他赛果出现，奖金则约等于10000元，刚好保本，损失的是投注冷门时本可获得更高收益的机会成本。


### 💎 总结
“奖金优化”是一个资金管理和平衡风险收益的工具，但需要理解其原理和风险。你可以根据对赛果的判断，选择合适的优化策略。表格总结了三种主流优化方法的核心区别：

| 比较项 | 🛡️ 平衡优化 | 🔥 博热优化 | ❄️ 博冷优化 |
| :--- | :--- | :--- | :--- |
| **核心目标** | **风险最低**，收益稳定 | **锁定热门**，最大化最可能结果的收益 | **博取冷门**，最大化高赔率结果的收益 |
| **资金策略** | 均匀分配，100%无风险 | 重点投资热门，其他结果保本 | 重点投资冷门，其他结果保本 |
| **潜在回报** | 稳定但较低 | 热门结果回报高，其他结果回报低 | 冷门结果回报极高，其他结果回报低 |
| **适合场景** | 对比赛全包追求无风险收益 | 对预测非常有把握，或想追求更高收益 | 追求高风险高回报，以小博大 |
| **风险等级** | **低** | **中** | **高** |
